# 业务资料口径

amount 是活动量，kg_per_unit 表示每一单位因子活动量的 kg 排放；换算仅允许 kWh/MWh 和 L/mL 的同量纲转换。allocation 为该活动分到产品的比例，非负且合计一；同一活动量的不确定性不能因分摊而独立化。source 相同表示共享同一因子来源，不意味着任意不同来源一定独立。interval 只声明上下界；normal 才声明分布标准差。活动缺因子须输出缺口而非按零求完整总量。输入中不确定性没有概率含义的部分不能生成无条件覆盖率承诺。

小样本用于手工核对字段和边界；历史样本只扩展观测量，不保证任何推断、优化或方案一定成立。实际分析应允许信息不足或条件冲突。

## 不确定性传播口径

- 共享来源：同一 source 的所有因子行共享一个不确定性驱动，组内完全相关。一个电力因子即使出现在几百行活动中，也只构成一份来源证据；来源级界宽与 sd 在组内直接相加，不能按行数开平方。
- 单位变换与分摊：单位换算只改变活动量权重，分摊比例只把同一驱动按比例切到产品，均为确定性线性变换，不创造新的不确定性，也不使各产品分摊相互独立。
- interval：只做硬界传播。同来源在共同极值处取得来源级上下界；只有当全部来源都是 interval 时，总量和产品才有有限硬界。interval 不支持 sd、分位数或覆盖率（如 95%）表述。
- normal：来源级 sd 为各行 amount×sd 之和。不同 source 之间的相关性未知：独立来源假设下给出 sd 与产品协方差（显式标注为条件结果），同时给出相关性未知时 sd 的 Fréchet 可行界 [max(0, 2σmax−Σσ), Σσ]。
- 混合来源：同一资料中 interval 与 normal 并存时，总量既无有限硬界也无整体覆盖率；同一 source 内混合两种声明时，该来源的界和 sd 都无法合成，标记为 unsupported。
- 缺因子：活动排放未知，排除在 known 中心值与一切界、sd 之外，作为 missing_factor 缺口输出，并在补测优先级中排在最前。

## 修订比较口径

- 资料修订效应只包含因子依据变化（factor_effect）与分摊依据变化（allocation_effect）；活动量变化、活动新增/移除、因子重新挂接归为经营活动变化。
- 共同活动按「旧量旧因子旧分摊 → 旧量新因子旧分摊 → 旧量新因子新分摊 → 新量新因子新分摊」四阶段替换，效应逐项可加并与新版本中心值对账。
- 每个版本的分析结果只解释该 revision 的资料；历史发布按当时因子与分摊解释，新版本导入不回写、不覆盖历史数字。
