# 业务资料口径

amount 是活动量，kg_per_unit 表示每一单位因子活动量的 kg 排放；换算仅允许 kWh/MWh 和 L/mL 的同量纲转换。allocation 为该活动分到产品的比例，非负且合计一；同一活动量的不确定性不能因分摊而独立化。source 相同表示共享同一因子来源，不意味着任意不同来源一定独立。interval 只声明上下界；normal 才声明分布标准差。活动缺因子须输出缺口而非按零求完整总量。输入中不确定性没有概率含义的部分不能生成无条件覆盖率承诺。

小样本用于手工核对字段和边界；历史样本只扩展观测量，不保证任何推断、优化或方案一定成立。实际分析应允许信息不足或条件冲突。
